# Visakhapatnam Institute for Pofessional studies – Full-Stack College Web & ERP Portal

A modern, responsive university web application and role-based ERP dashboard built with **Next.js (App Router)**, **React**, **TypeScript**, and **Tailwind CSS**.

## Key Features
- **Interactive Academic Catalog:** Filterable degree programs across Engineering, Management, and Sciences with curriculum highlights and seat metrics.
- **Admissions Inquiry Workflow:** Validated prospective student inquiry card with instant feedback and prospectus request handling.
- **Role-Based Student & Admin ERP (`/portal`):**
  - **Student View:** Real-time CGPA overview, subject-wise attendance and internal marks table, fee status, and downloadable exam hall tickets.
  - **Admin Dashboard:** Full CRUD controls to publish or delete live campus notices and review/approve incoming admissions inquiries.
- **AI Campus Assistant:** Floating conversational widget available across all routes to answer visitor questions on admissions, placements, scholarships, and hostel fees.

## Tech Stack
- **Framework:** Next.js 16 (App Router, Turbopack)
- **Language:** TypeScript
- **Styling & Icons:** Tailwind CSS, Lucide React
- **Deployment:** Vercel CI/CD via GitHub
